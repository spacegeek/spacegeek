# SpaceGeek

I am an independent researcher and systems designer with professional experience in aerospace quality, nondestructive testing, electronics, manufacturing, corporate facilities, industrial maintenance, safety and operations.

My work is concerned with environments where reliable records, technical judgment, equipment condition and organizational continuity must remain connected. ## ConSERVA

**ConSERVA** is a research and software project concerned with provenance, preservation and the relationships among records, objects, observations, evidence and decisions.

The project investigates how information systems can preserve context as records evolve, conclusions change and new evidence becomes available.

**Current public status:** Research and documentation phase. The project implementation is not yet published.

## DeVISU

**DeVISU** is an operational-view stewardship project concerned with how interfaces represent changing systems, evidence, uncertainty and responsibility.

The project investigates how an operational view can remain understandable, traceable and current without hiding the limitations or history of the information it presents.

**Current public status:** Research and documentation phase. The project implementation is not yet published.
